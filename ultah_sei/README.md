# Happy Birthday Website 🎂💖

Website ucapan ulang tahun spesial estetik bertema pink, dilengkapi countdown akurat, pemutar musik LANY - Soft, galeri foto polaroid bersih minimalis, video player, dan efek confetti.

## ✨ Fitur:
- ⏰ **Countdown Timer**: Menghitung mundur akurat menuju 18 September 2026 pukul 00:00 WIB.
- 🔐 **Secret Passcode (PIN: 0918)**: Akses buka kunci sebelum waktu selesai menggunakan PIN rahasia.
- 🎵 **Music Player**: Lagu *LANY - Soft* yang otomatis dapat diputar / di-pause.
- 📸 **Hero Section**: Foto utama yang menyatu (*blended gradient*) dengan latar belakang pink.
- 🎞️ **Clean Polaroid Gallery**: Galeri foto polaroid estetik bersih tanpa teks dengan fitur Lightbox preview.
- 🎬 **Video Moments**: Pemutar video kenangan format vertikal.
- 🎁 **Pesan & Doa Tersembunyi**: Tombol kado interaktif dengan ledakan confetti.
- 📱 **Mobile Optimized**: Ringan, mulus 60fps di iPhone (iOS Safari), Android (Chrome), maupun Laptop.

## 🚀 Cara Menjalankan:
Cukup buka file `index.html` di browser favoritmu (Chrome, Safari, Edge, Firefox).
